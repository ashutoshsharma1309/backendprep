# Phase 0 Exercises

These are standalone drills — do them in a scratch Maven project, **not**
inside `project/`. The Library Service codebase starts in Phase 1.

1. `java-drills.md` — the six "Try it yourself" tasks from Module 1, listed
   together so you can knock them out in one sitting.
2. `sql-schema.sql` — the sample schema from Module 5. Load it into a local
   Postgres/SQLite/H2 instance and run every query in that module against it.
3. `git-conflict-drill.md` — step-by-step instructions to create and resolve
   a realistic merge conflict on your own, without a partner.

Bring your solutions to your mentor check-in before starting Phase 1.
